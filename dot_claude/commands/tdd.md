Invoke the tdd-guide agent to enforce test-first development on the current feature or bug fix.

Use for: starting a new feature, fixing a bug, or any behavioral change that needs test coverage.

The tdd-guide will:
1. Write failing tests that specify the expected behavior (RED)
2. Implement the minimal code to make them pass (GREEN)
3. Refactor while keeping tests green

Tests are written before implementation — not after.
